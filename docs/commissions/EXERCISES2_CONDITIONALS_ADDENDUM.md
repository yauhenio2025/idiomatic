# Addendum: CONDITIONALS batches (extends EXERCISES2_BATCH_COMMISSION.md)

Everything in the base batch commission applies. CONDITIONALS inputs are
FULL SENTENCES, not connectors, so five rules change:

1. **category** must be one of the sentence-level values:
   `real-condition` (open/likely), `counterfactual` (past or present
   unreal), `mixed-condition` (unreal past → present result or similar),
   `habitual` (whenever/every-time readings). Not the connector values.
2. **tl** = the full target-language translation of the input sentence —
   the best rendering an educated native would produce, correct tense
   architecture above all.
3. **example_tl** = a NEW sentence, not a copy of `tl`: same conditional
   architecture, different content, learner's professional register
   (tech criticism / geopolitics / media), 18–30 words. This doubles the
   practice material per note.
4. **cloze** wraps the GOVERNED VERB GROUPS of `example_tl` — the verb
   of the condition clause and the verb of the result clause, each in
   its own `{{c1::…}}` (include attached clitics/auxiliaries; the
   remaining sentence must stay grammatical as a frame).
5. **trap** targets tense-architecture interference for THIS learner:
   es/pt/it subjunctive-system crossings (pt future subjunctive vs es
   present subjunctive after si/se; it congiuntivo trapassato), fr
   si + imparfait (never conditional after si), de Konjunktiv II with
   würde-avoidance in written German. Real hazards only.

Triage note: expect a HIGHER keep rate than CONNECTING (~70–85%) — these
are authored drill sentences, not scraped lists; drop only true
duplicates of another kept item's exact architecture + content overlap,
or broken English.

**Italian sessions only**: `old_back` comes from the verified 2026
corpus rebuild, not the defective 2023 deck — treat it as a
good-quality reference translation (you may adopt it as `tl` when it is
already optimal), but the hostile verification pass still applies.
