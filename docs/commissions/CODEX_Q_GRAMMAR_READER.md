## Goal

Theoretical material the learner can READ (tablet/phone) mapped to his
actual weaknesses — a curated, properly-attributed personal grammar
reader, not a link dump.

## Tasks

1. **Source survey** (`docs/reader/SOURCES.md`): verify the three
   strategy-doc CC sources still exist + license terms; find 3-6 more
   genuinely open (CC BY / CC BY-SA / public domain) grammar-prose
   sources per language (open textbooks, university OER, Wikibooks
   where quality allows). URL, license, quality verdict, what it
   covers. Reject anything paywalled/all-rights-reserved.
2. **The reader** (`docs/reader/{lang}/NN_{slug}.md`, 6-10 chapters
   per language): for each of his top weak categories, ADAPT (CC
   licenses permit, with attribution) the best source prose into a
   tight chapter: 600-1,200 words, his attested errors inserted as
   "you specifically do this" callouts, examples swapped toward his
   news/geopolitics register where the license allows adaptation.
   Every chapter ends with attribution + license + source link
   (BY-SA chapters must note share-alike). Where no usable open prose
   exists for a topic, WRITE the chapter yourself and mark it
   original.
3. **Index** (`docs/reader/README.md`): reading order per language
   (evidence-priority), license summary table, and a note on
   podcast-conversion candidates (chapters that would work read
   aloud — commission M can absorb them as season 2).

Quality bar: linguistic accuracy over coverage; never misattribute;
never include content whose license you could not verify.
