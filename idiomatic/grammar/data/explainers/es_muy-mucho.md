## SCRIPT

Seven recorded errors show the same switch going both ways. On the adjective side, the record contains these forms:

TL: mucho de moda

TL: mucho dificil

TL: mucho importante

TL: mucho profesional

On the noun side, the record contains these two wrong forms:

TL: muy tráfico

TL: muy frio

For the final case, the wrong side was stored only as the bare word:

TL: muy

The teacher’s target was:

TL: hacía mucho calor

The spellings above preserve the recorded wrong sides; the structural issue here is the choice of quantity word.

Here is the memory rule. The short, unchanging intensifier goes directly before an adjective or adverb. The longer form handles quantities: it agrees when it comes before a noun, and it is invariable when it modifies a verb.

Contrast one: ask what kind of word follows. An adjective takes the intensifier; a noun takes the quantity word.

TL: El análisis es muy claro.

TL: El análisis contiene mucha información.

The phrase meaning fashionable behaves like an adjective, even though it contains a preposition.

TL: El formato está muy de moda.

Contrast two: quantity before a noun must agree with that noun.

TL: Hay mucho tráfico y muchas demoras.

TL: El proyecto exige mucha paciencia y muchos recursos.

Weather expressions can disguise nouns as descriptions. In the standard expressions for cold and heat, the weather word is a noun, so it takes the quantity form.

TL: Hace mucho frío.

TL: Hacía mucho calor.

The same word can instead be an adjective in a different frame; then the intensifier is correct.

TL: El café está muy frío.

Contrast three: after a verb, the quantity form is an adverb and never agrees.

TL: La audiencia creció mucho.

TL: Las audiencias crecieron mucho.

Contrast four: comparatives also choose the quantity form. Think “much more,” not “very more.” For equal degree, the neighboring pair follows the same division: one form before an adjective, the other after a verb.

TL: Este episodio es mucho más breve.

TL: El segundo informe es tan claro como el primero.

TL: Ahora trabajamos tanto como antes.

Self-test one. Say: the proposal is very ambitious.

[PAUSE]

TL: La propuesta es muy ambiciosa.

Self-test two. Say: there was a lot of traffic.

[PAUSE]

TL: Hubo mucho tráfico.

Self-test three. Say: this version is much more precise.

[PAUSE]

TL: Esta versión es mucho más precisa.
