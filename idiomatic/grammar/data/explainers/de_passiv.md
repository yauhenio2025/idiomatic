## SCRIPT

This fossil has different evidence from the adjective-ending errors. No wrong passive form was recorded, so there is no learner error to quote. Instead, the teacher supplied roughly thirty-five passives from 2019 through 2024, while the record contains no spontaneous passive production. The evidence therefore suggests avoidance: the construction needs to become available quickly enough to use.

The memory rule for the ordinary transitive process passive is: promote the accusative object to subject position, conjugate the passive auxiliary, and send the lexical verb’s past participle to the end. The agent is optional; include it only when it matters.

Contrast one changes viewpoint, not the event.

TL: Die Redaktion veröffentlicht den Bericht.

TL: Der Bericht wird von der Redaktion veröffentlicht.

The active sentence foregrounds the editors. The passive sentence foregrounds the report. The old accusative object becomes nominative, so it controls agreement on the finite auxiliary.

Contrast two changes tense on the auxiliary while leaving the participle in place.

TL: Der Bericht wird heute veröffentlicht.

TL: Der Bericht wurde gestern veröffentlicht.

One teacher-supplied example uses exactly that simple-past frame:

TL: Das Buch wurde geschrieben.

Contrast three separates an unfolding process from a resulting state.

TL: Der Bericht wird veröffentlicht.

TL: Der Bericht ist veröffentlicht.

The first presents publication as an event. The second describes the report as already in the published state. For the perfect tense of the process passive, use the shorter special form:

TL: worden

The ordinary perfect of the verb meaning “become” uses the longer form:

TL: geworden

That longer form does not belong in the perfect process passive.

TL: Der Bericht ist veröffentlicht worden.

Contrast four adds a modal. The modal is finite; the participle and passive infinitive collect at the end.

TL: Der Bericht muss heute veröffentlicht werden.

The lesson record repeatedly supplied this pattern, including:

TL: Sprachlehrer konnten noch nicht ersetzt werden.

It even contains this advanced counterfactual stack:

TL: Es hätte letztes Jahr veröffentlicht werden sollen.

Self-test one. Turn the active sentence into a present passive.

TL: Die Redaktion prüft den Artikel.

[PAUSE]

TL: Der Artikel wird von der Redaktion geprüft.

Self-test two. Turn the sentence into a simple-past passive.

TL: Der Verlag veröffentlichte das Buch.

[PAUSE]

TL: Das Buch wurde vom Verlag veröffentlicht.

Self-test three. Say: the report must be corrected.

[PAUSE]

TL: Der Bericht muss korrigiert werden.
